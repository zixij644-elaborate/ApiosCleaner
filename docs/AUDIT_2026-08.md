## 已验证的争议项

- **junction 过滤是 no-op（误报）**：安全 agent 声称 `FileType::is_symlink()` 对
  junction 返回 false（论据 std 仅查 SYMLINK tag）。实测证伪：junction 被过滤
  （orphan 106→96，Application Data/Documents/Templates 消失），std 实际检查
  FILE_ATTRIBUTE_REPARSE_POINT 位。结论：功能正常，仅补 is_reparse_point 双保险。
- **f_flags u16→u32（误报）**：FFI agent 声称 SHFILEOPSTRUCT.fFlags 应为 u32。
  查 MSDN：fFlags 类型为 `FILEOP_FLAGS`（`typedef WORD`），u16 正确，不改。
